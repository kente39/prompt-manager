# 나만의 프롬프트 관리 프로그램

자주 쓰는 AI 프롬프트를 콘솔에서 추가·조회·검색·즐겨찾기할 수 있는 Python 프로그램입니다.
Python 표준 기능만 사용하며, 별도 설치 없이 바로 실행됩니다.

## 실행 방법

```bash
python app.py
```

실행하면 메뉴가 나타나고, 번호를 입력해 기능을 선택합니다.

## 기능

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트 등록 |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호·카테고리·즐겨찾기 여부와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리에 속한 프롬프트만 출력 |
| 4 | 검색 | 제목·내용에 검색어가 포함된 프롬프트 찾기 |
| 5 | 상세 보기 | 번호로 고른 프롬프트 1개의 전체 내용 출력 |
| 6 | 즐겨찾기 관리 | 번호로 고른 프롬프트의 즐겨찾기를 켜고/끄기(토글) |
| 7 | 즐겨찾기 목록 | 즐겨찾기(⭐)한 프롬프트만 모아서 출력 |
| 0 | 종료 | 프로그램 종료 |

## 카테고리

소설 · 에세이 · 자기계발 · SF · 만화 · 미스터리

프롬프트 추가 시 위 목록에서 번호로 고르거나, `0`을 눌러 직접 입력할 수 있습니다.

## 데이터 저장 방식

프롬프트는 **프로그램 실행 중에만 메모리에 저장**되며, 종료하면 초기화됩니다.
기본 프롬프트 3개가 미리 등록되어 있어 실행 직후 바로 기능을 확인할 수 있습니다.

## 입력 처리

잘못된 입력에 프로그램이 멈추지 않도록 검증을 넣었습니다.

- 빈 값을 입력하면 다시 입력을 요청합니다.
- 숫자가 아니거나 범위를 벗어난 번호는 거르고 다시 요청합니다.

## 코드 구조

기능별로 함수를 분리했으며, `main()`에서 메뉴 루프를 돌며 선택에 따라 각 함수를 실행합니다.

- `show_menu` : 메뉴 출력
- `add_prompt` / `show_list` / `show_by_category` / `search_prompt` / `show_detail` / `toggle_favorite` / `show_favorites` : 각 기능
- `input_non_empty` / `input_number` : 입력 검증 유틸
- `main` + `if __name__ == "__main__":` : 실행 진입점

## 개발 환경

- Python 3.10 이상
- 외부 라이브러리 없음(표준 기능만 사용)
